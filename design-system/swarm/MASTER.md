- `DESIGN_VARIANCE: 5` (classic centered SaaS — user override)

- **Body:** Inter

- Nav CTA: blue→purple gradient (video)

## Accent lock

Coral for primary actions site-wide. Gradient reserved for nav CTA + headline emphasis word + background wave.
